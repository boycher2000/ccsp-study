# CCSP 備考筆記與題庫

依 ISC2 **CCSP 2026-08-01 生效大綱**(6 個 domain、38 個子項)整理的筆記,加上原創練習題與抽題網頁。純靜態網站,不需要後端。

> 這不是 ISC2 官方資源,與 ISC2 無關。題目是原創練習題,**不是考古題**,也不是任何出版社或第三方網站內容的複製。內容仍是草稿,請以官方文件為準。

## 功能

- 38 個子項的筆記,每個子項附官方大綱要點清單,用來檢查有沒有漏。
- 刷題:自訂題數(預設 100)、依官方權重抽題、練習模式(作答後立刻看解析)與模擬考模式(交卷後看解析)。
- 每題有整體解析與每個選項的說明;每題標示狀態(`draft` / `reviewed` / `verified`)。
- 錯題本與作答紀錄只存在瀏覽器的 localStorage,不會上傳。

## 本機開啟

```bash
python -m http.server -d docs 8000
```

然後開啟 <http://localhost:8000>。不要直接用 `file://` 開啟,瀏覽器會擋住資料載入。

## 專案結構

```
docs/                 網站(GitHub Pages 可直接從 /docs 發布)
  index.html
  assets/             app.js、style.css
  data/
    outline.json      官方大綱:6 個 domain、38 個子項與要點
    notes/d1..d6.md   筆記,每個子項一節 (## 1.1 …)
    questions/d1..d6.json   題庫
scripts/validate.py   資料驗證與覆蓋率報告
CONTENT_GUIDE.md      出題與寫筆記的規則
CORRECTIONS.md        已發現的事實問題與處理方式、待核對清單
```

## 驗證資料

```bash
python scripts/validate.py
```

檢查大綱 38 項、每個子項都有筆記、題目欄位完整、選項與解析數量一致、題目編號不重複,並印出各 domain 的題數與目標(1000 題依官方權重分配)的差距。
