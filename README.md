# CCSP 備考筆記與題庫

依 ISC2 **CCSP 2026-08-01 生效大綱**(6 個 domain、38 個子項)整理的筆記,加上原創練習題與抽題網頁。純靜態網站,不需要後端。

> 這不是 ISC2 官方資源,與 ISC2 無關。**題庫是私人的,不在這個公開 repo 裡**(見下方「私人題庫」)。筆記是原創整理,不是考古題,也不是任何出版社或第三方網站內容的複製。內容仍是草稿,請以官方文件為準。

## 兩個獨立入口

| 入口 | 路徑 | 內容 |
|---|---|---|
| 筆記 | `/notes/` | 總覽與總訣、責任分擔總表、縮寫速查;38 個子項各有白話重點、名詞解釋、比較表、口訣、延伸知識、情境演練、考點與易錯陷阱;全文搜尋 |
| 刷題 | `/quiz/` | **開放式情境題**(自己寫答案、對照要點自評、可複製給 AI 批改)與選擇題;題數可選 5/10/20/30/50;依官方權重抽題;錯題本、進度。**題庫只在本機載入** |

兩邊互通:筆記頁有「練習這個子項」,題目解析有「看筆記」。進度與錯題只存在瀏覽器的 localStorage,不會上傳。

## 本機開啟

```bash
python -m http.server -d docs 8000
```

然後開啟 <http://localhost:8000>。不要直接用 `file://` 開啟,瀏覽器會擋住資料載入。

## 專案結構

```
docs/                    網站(GitHub Pages 從 /docs 發布)
  index.html             入口頁
  notes/index.html       筆記入口
  quiz/index.html        刷題入口
  assets/                common.js(Markdown 渲染、資料載入)、notes.js、quiz.js、style.css
  data/
    outline.json         官方大綱:6 個 domain、38 個子項與要點
    notes/overview.md    總覽與總訣
    notes/d1..d6.md      每個子項一節 (## 1.1 …)
    private/questions/     私人題庫(git 忽略,不會發布):d1..d6.json 選擇題、o1..o6.json 開放式情境題、index.json 索引
private/                 私人原始資料(git 忽略),例如你自己買的題庫整理出的概念清單
scripts/validate.py      資料驗證與覆蓋率報告
CONTENT_GUIDE.md         寫筆記與出題的規則
CORRECTIONS.md           已發現的事實問題與處理方式、待核對清單
```

## 驗證資料

```bash
python scripts/validate.py
```

檢查項目:
- 大綱 38 項、權重加總 100。
- **每個子項都有筆記**,並且筆記開頭的 `<!-- covers: 1,2,… -->` 必須恰好涵蓋該子項的**所有官方要點**(這是筆記完整度的機器檢查)。
- 筆記必須有「白話重點」「名詞解釋」「考點」三個區塊;字數太短會警告。
- 題目欄位完整、選項與解析數量一致、題目編號不重複。
- 印出各 domain 題數與目標(1000 題依官方權重分配)的差距。

## 目前進度

- 筆記:38/38 個子項已有草稿(約 7.7 萬字),每個子項都對照過官方要點;並整合了公開筆記(Jeff)中與 2026 大綱重疊且正確的知識點。
- 題庫(私人,本機):選擇題 38 題(舊種子題)+ 開放式情境題 12 題(新格式);**之後新題一律用開放式情境題**。
- 所有題目為 `draft`:尚未用權威來源逐題核對。

## 私人題庫

題庫放在 `docs/data/private/questions/`,並由 `.gitignore` 排除,**不會被提交,也不會發布到 GitHub Pages**。原因:題目可能參考你自己購買或練習的第三方題庫,不適合公開散布。

- 在自己的電腦用 `python -m http.server -d docs 8000` 開啟網站,刷題頁就會載入私人題庫;發布到網路上的網站則沒有題目,刷題頁會顯示說明。
- 新增或修改題庫檔後,執行 `python scripts/validate.py`:會驗證題目,並更新 `index.json`(網站靠它知道有哪些檔案)。
- `private/` 資料夾放原始資料(同樣被忽略)。
